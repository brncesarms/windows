# 👤 Windows Usuários: Exibir Nome do Computador e Contas

> [!info] Comandos rápidos para identificar o hostname atual e listar todos os usuários locais cadastrados no sistema.

---

### 👤 Exibir nome do computador
```powershell
hostname
```

### 👤 Exibir usuários cadastrados
```powershell
net user
```

> [!tip] Alternativa via PowerShell
> ```powershell
> Get-LocalUser
> ```
